# PDF／JSON出力の検証記録

## 出力の流れ（2026-11-24 改訂）

「PDF・データを出力」を1回押すと、同じ時点の入力内容からPDFとJSONを作り、端末に合わせて保存します。

| 端末 | 動作 |
|---|---|
| パソコン（Chrome・Edge） | 押した直後に保存先フォルダーを選ぶ（`showDirectoryPicker`、`id` で書類ごとに前回のフォルダーを開く）→ PDF作成 → そのフォルダーにPDF・JSONを保存。同名ファイルは上書き確認。フォルダー選択をキャンセルすると出力も中止 |
| パソコン（Firefox・Safari） | フォルダー選択が使えないため、両方を自動ダウンロード |
| 携帯（iPhone・iPad・Android） | 「📤 共有（PDF・データ）」1回で共有メニューに両方を渡す。ファイルごとの「共有」でPDFだけ送れる。最初のタップが有効なうちに作成が終われば共有メニューが自動で開く |
| 携帯で複数ファイル共有に非対応 | 両方を自動ダウンロード |
| PDF作成失敗 | 作成済みのJSONだけを個別に保存できる（自動保存はしない） |

2026-07の版（`cbedae1`）の「押す → フォルダーを選ぶ → 保存」の流れを元に、前回フォルダーの記憶と上書き確認を加えました。

## 再現方法

```bash
node --test tests/*.test.cjs
```

`tests/document-export.test.cjs` は `tests/helpers/export-fixture.cjs` のブラウザAPI模擬環境で、実際の `document-export.js` を実行します。

## 自動テストで確認している内容

| 確認内容 | 結果 |
|---|---|
| PCでPDF・JSON・両方の出力 | 出力ボタン1回で全ファイルがダウンロードされる |
| PCでWeb Share対応ブラウザ | 共有メニューを開かずダウンロードする |
| 携帯で両方の共有 | 1回の操作でPDF・JSONを一緒に共有。キャンセル後はPDFを作り直さず再試行できる |
| 携帯でタップが有効なまま完了 | 追加タップなしで共有メニューが開く |
| 携帯で複数ファイル共有に非対応 | 両方を自動ダウンロード |
| PDFとJSONの同時点整合 | 作成中に入力を変えても、両方が出力開始時点の内容になる |
| 二重実行 | 作成中の再クリックで二重に作成しない |
| 中止・生成エラー・画像欠落・時間切れ | 一時ページを片付け、入力ロックを解除し、JSONは救済保存できる |
| 共有中のEsc | 共有を中断扱いにせず、ファイルを保持する |

## 残る確認事項（実機）

- iPhone Safari／Android Chrome での「📤 共有（PDF・データ）」と、LINE・「ファイルに保存」への両方の受け渡し。
- Chrome／Edge（PC）での実際のフォルダー選択・前回フォルダーの再表示・日本語ファイル名での保存（テスト用ブラウザの一時領域は日本語名を書き込めないため、名前を変換して検証）。
- Firefox／Safari（PC）での2ファイル連続ダウンロード。
- 実PDFのサイン・画像・日本語文字・金額・複数ページの目視確認。
