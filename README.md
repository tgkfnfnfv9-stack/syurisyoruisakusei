# 小林機械 現場ツール

株式会社小林機械の従業員が、現場・事務で使う業務ツール集です。
見積書・報告書を**スマホ（iPhone）やPC**で作成し、その場でPDF・JSONデータを保存できます。
入力内容は端末内の下書きに加え、設定済みの共通Google Driveへ自動保存します。

🔗 公開ページ: <https://tgkfnfnfv9-stack.github.io/syurisyoruisakusei/>
🏢 会社サイト: <https://www.kkmt.co.jp>

## 使い方・注意点

- **iPhone の Safari 推奨**です。
- 写真添付・在庫検索など**社内サイト（kkmt.co.jp）を開く機能**は、**ログイン済みの Safari** で使ってください。Documents by Readdle などのアプリ内ブラウザでは、ログイン情報が無く開けないことがあります。
- 見積書の「距離を自動取得」を使う場合は、Google Cloud で **Routes API を有効化**し、**APIキー**を各ツールの入力欄に貼り付けてください（キーは端末内にのみ保存されます）。
- 読み込み済みのページでは、ネット接続なしでも入力・プレビュー・PDF/JSON出力を行えます。初めてページを開くとき、距離の自動取得、在庫サイト、共通Driveとの同期にはネット接続が必要です。

## 保存・読み込み

- 見積書は**高コン番号または件名**、報告書は**高コン番号**を保存先の識別に使います。番号がある書類は番号を優先します。
- 入力内容はブラウザの `localStorage` に下書きとして保存し、共通Driveへ自動保存します。未接続や通信失敗時は、識別項目がある書類を端末内の未同期データとして保管します。
- 再接続時に未同期データを同期します。他の端末の更新と競合した場合は上書きせず、端末内の変更を保持してエラーを表示します。必要な変更をJSONで控えてから、Driveの最新データを読み込んでください。
- JSONファイルの読み込み・見積書の報告書への取り込みでは、読み込んだ直後にDriveを上書きしません。その後の入力変更は自動保存の対象になります。
- 報告書のPDFプレビューは閲覧用です。修正は通常の入力欄から行います。
- 報告書・見積書のプレビューは、パソコンではプレビュー上のマウスホイール、携帯では2本指を開く・閉じる操作で拡大縮小できます。表示倍率は20〜400%で、通常の1本指スクロールや見積書の備考・品名編集は維持します。
- 拡大率は閲覧専用です。保存するPDF・印刷の原寸レイアウトやJSONの内容は変わらず、再読み込み時には100%表示へ戻ります。
- ブラウザの保存容量不足や保存禁止設定では下書き・未同期データを保管できません。保存状態を確認し、必要に応じてJSONデータを控えてください。

## 共通Driveバックエンドの更新

GitHubのHTML・JavaScriptを更新しても、公開済みApps Scriptのコードは自動では更新されません。
`apps-script/Code.gs` を変更した場合は、保存先Googleアカウントでコードを更新し、**既存のウェブアプリを新しいバージョンへ再デプロイ**してください。詳細は [設定・更新手順](apps-script/README.md) を参照してください。

新しいバックエンドは旧「見積書」フォルダのデータも読み込めます。最新版の確認後に保存すると、同じファイルIDのまま「見積もり」フォルダへ移動して更新します。現在の「見積もり」フォルダに同じ書類がある場合は、そちらを優先します。

## 技術メモ

- ツール本体はHTML、Drive共通処理は同じサイトの `google-drive.js` に分離
- PDF生成: jsPDF + html2canvas
- 下書き・未同期データ: ブラウザの `localStorage`
- 共通保存: Google Apps Scriptを経由して、公開者のGoogle DriveへJSONを書き込み
- 同時更新の保護: 書類の更新番号とApps Scriptのロックで競合を検出

## 検証

Node.jsで、保存・競合・旧データ互換・読込処理を検証できます。

```bash
node --test tests/*.test.cjs
node tests/validate-drive-integration.cjs
```

これらのテストは通信・Driveを模擬します。実端末でのPDF保存、Google側の公開権限、実際にデプロイされているバックエンドは別途動作確認が必要です。

## 見積書と報告書の作業費

見積書は通常作業時間と17:30以降の時間を分けて入力します。報告書は同じ日・同じ作業者の総作業時間を合算し、1日8時間を超えた分を割増料金で計算します。今回の修正では、書類ごとの料金基準を変更していません。

見積書を報告書へ取り込むと人数・合計時間・部品等は引き継ぎますが、作業費は報告書の基準で再計算します。夜間作業を含む見積書や、作業費を手入力した見積書は、取込前後で作業費が変わる場合があります。取込後に作業者・日付・時間と計算結果を確認してください。
