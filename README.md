# 小林機械 現場ツール

株式会社小林機械の従業員が、現場・事務で使う業務ツール集です。
見積書・報告書を**スマホ（iPhone）やPC**で作成し、その場でPDF・JSONデータを保存できます。
入力内容は端末内に下書きとして自動保存します。

🔗 公開ページ: <https://tgkfnfnfv9-stack.github.io/syurisyoruisakusei/>
🏢 会社サイト: <https://www.kkmt.co.jp>

---

## 事業内容

中古の工作機械全般の**買取・修理・オーバーホール**、**改造してからの再販売**を行っています。
外注修理も承ります。また、KBK系列会社に**重量屋（重量物運搬）**があります。

## ツール一覧

| ツール | ファイル | 内容 |
|---|---|---|
| 見積書 | `見積書.html` | 拠点・距離・人員から見積書を作成し、PDF保存 |
| 報告書メーカー | `報告書メーカー.html` | 作業内容・担当者・サインなどから報告書を作成し、PDF・JSONを保存 |

トップページは `index.html`、JSONデータの読み込みは `local-data.js`、AI取込は `ai-import.js`（形式は `AI_SCHEMA.md`）、PDF・データ出力は `document-export.js` です。

## 使い方・注意点

- **iPhone の Safari 推奨**です。
- 写真添付・在庫検索など**社内サイト（kkmt.co.jp）を開く機能**は、**ログイン済みの Safari** で使ってください。Documents by Readdle などのアプリ内ブラウザでは、ログイン情報が無く開けないことがあります。
- 見積書の「距離を自動取得」を使う場合は、Google Cloud で **Routes API を有効化**し、**APIキー**を各ツールの入力欄に貼り付けてください（キーは端末内にのみ保存されます）。
- 読み込み済みのページでは、ネット接続なしでも入力・プレビュー・PDF/JSON出力を行えます。初めてページを開くとき、距離の自動取得、在庫サイトにはネット接続が必要です。

## 保存・読み込み

- 入力内容はブラウザの `localStorage` に下書きとして自動保存します。共通Driveへの保存・検索・取り込みは廃止しました。
- 書類を残すときは「PDF・データを出力」を押します。**1回の操作でPDFとデータ（JSON）の両方**を出力します。
  - **パソコン**：PDFとJSONを続けてダウンロードフォルダーへ保存します。Chromeなどで「複数ファイルのダウンロード」の確認が出たら「許可」を押してください（初回のみ）。
  - **携帯（iPhone・Android）**：PDF作成後に「PDF・データをまとめて保存」を押すと、共有メニューに両方のファイルが入ります。「ファイルに保存」でまとめて保存できます。PDF作成が早く終わった場合は、ボタンを押さなくても共有メニューが自動で開きます。
  - 自動で保存されなかった場合は、画面の「ダウンロード」から1つずつ保存し直せます。
- 「📂 読み込み」で保存したJSONを開くと、続きから編集できます。報告書の「📥 見積取込」では見積書のJSONを取り込めます。
- 報告書のPDFプレビューは閲覧用です。修正は通常の入力欄から行います。
- 報告書・見積書のプレビューは、パソコンではプレビュー上で Ctrl（Macは⌘）を押しながらマウスホイール（トラックパッドはピンチ）、携帯では2本指を開く・閉じる操作で拡大縮小できます。表示倍率は20〜400%で、普通のホイール・2本指スクロールや通常の1本指スクロール、見積書の備考・品名編集は維持します。
- 拡大率は閲覧専用です。保存するPDF・印刷の原寸レイアウトやJSONの内容は変わらず、再読み込み時には100%表示へ戻ります。
- ブラウザの保存容量不足や保存禁止設定では下書きを保管できません。必要に応じてJSONデータを出力して控えてください。

## AI取込（一番早い使い方）

AI（ChatGPT・Claude・Muse等）に内容を伝えるだけで、見積書・報告書が全欄埋まった状態で開きます。

1. AIに内容を伝える（例：「見積書。高コン245001、岡機械刃物研磨、小山市城東4-5-1、12/3に2人で7時間、本社から片道36km・1時間、ベアリング原価24000円×2」）
2. AIが返した **リンクを押す** → 完成（現在の入力がある場合は置き換えの確認が出ます）
3. リンクが無い・開けないときは、AIの返答をコピー →「🤖 AI取込」→「**📋 コピーしたAIの返答を取り込む**」

- 初回だけ、ツールの「🤖 AI取込」→「AIへの指示文をコピー」でAIに渡す指示文をコピーし、内容と一緒に送ります（下の「AIに覚えさせる」をすると毎回は不要）
- 形式は [AI_SCHEMA.md](AI_SCHEMA.md)（「PDF・データを出力」で保存されるJSONと同一形式）。URLに `?ai=1` を付けると取込画面が開きます
- 金額（作業費・交通費・移動費・部品売価・税・合計）はツールが自動計算します。AIは元データだけを入れます
- 報告書のサインは取り込んだ後に記入してください。報告書のAI取込には見積書のJSONも貼れます（「📥 見積取込」と同じく変換）

### AIに覚えさせる（毎回の指示文を省く・おすすめ）

一度登録すれば、以後は「見積書、高コン○○、…」と話しかける（音声入力でも可）だけでリンクが返ってきます。手書きメモや前回の書類の写真を渡して作ってもらうこともできます。

| AI | 設定場所 | 登録するもの |
|---|---|---|
| ChatGPT | 「GPT」を作成 →「指示」 | 下の指示文。「知識」に `AI_SCHEMA.md` をアップロード。「コードインタープリター」をオン（リンク作成に使用） |
| Claude | 「プロジェクト」→「プロジェクトの指示」 | 下の指示文。「プロジェクトナレッジ」に `AI_SCHEMA.md` を追加 |
| Muse・その他 | カスタム指示・システムプロンプト | 下の指示文と `AI_SCHEMA.md` の内容 |

登録する指示文（例）：

> あなたは株式会社小林機械の書類作成係です。「見積書」「報告書」と言われたら、AI_SCHEMA.md の形式でデータ（JSON）を作り、AI_SCHEMA.md の「一番早い使い方」のとおり、ツールを開くリンク（コード実行で作成）と同じJSON（```json）を返してください。金額は計算せず、分からない項目は省略してください。足りない情報があっても質問は最小限にし、分かる範囲で作ってください。

## 技術メモ

- ツール本体はHTML、JSON読込は `local-data.js`、PDF・JSON出力は `document-export.js`、プレビュー拡大は `preview-zoom.js`
- PDF生成: jsPDF + html2canvas
- 下書き: ブラウザの `localStorage`

## 検証

Node.jsで、計算・読込・出力処理を検証できます。

```bash
node --test tests/*.test.cjs
```

これらのテストはブラウザAPIを模擬します。実端末でのPDF保存・共有は別途動作確認が必要です。

## 見積書と報告書の作業費

見積書は通常作業時間と17:30以降の時間を分けて入力します。報告書は同じ日・同じ作業者の総作業時間を合算し、1日8時間を超えた分を割増料金で計算します。今回の修正では、書類ごとの料金基準を変更していません。

見積書を報告書へ取り込むと人数・合計時間・部品等は引き継ぎますが、作業費は報告書の基準で再計算します。夜間作業を含む見積書や、作業費を手入力した見積書は、取込前後で作業費が変わる場合があります。取込後に作業者・日付・時間と計算結果を確認してください。
